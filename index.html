Model Information

  • Architecture: DCT + CNN branch (TensorFlow/Keras) fused with a Graph Attention Network branch (PyTorch Geometric)
  • Graph nodes: Photo, Name, Date of Birth, Signature, QR Code, Document Number
  • Fusion: Concatenated CNN + GAT features → Dense classifier
  • Explainability: Grad-CAM heatmap over the frequency-domain (DCT) image
  • Output classes: Genuine / Forged
